# Viper Ping — Download Center

صفحه فارسی دانلود خودکار آخرین نسخه رسمی **v2rayNG** و **v2rayN** از GitHub Releases.

## امکانات

- اندروید: APK نسخه Universal و سایر معماری‌ها، دانلود خودکار Universal پس از ۱۰ ثانیه (قابل لغو)
- ویندوز، لینوکس و macOS: انتخاب فایل‌ها و معماری‌ها از نسخه رسمی v2rayN
- نسخه‌های قدیمی و امکان نمایش نسخه‌های Beta
- تاریخ انتشار، توضیحات نسخه، حجم فایل و لینک مستقیم رسمی
- رابط فارسی RTL و سازگار با موبایل
- بدون سرور، بدون توکن و بدون نیاز به بروزرسانی دستی لینک‌ها

## روش کار

جاوااسکریپت سایت هنگام باز شدن صفحه این API را فراخوانی می‌کند:

- `https://api.github.com/repos/2dust/v2rayNG/releases?per_page=60`
- `https://api.github.com/repos/2dust/v2rayN/releases?per_page=60`

اولین انتشار غیرآزمایشی به‌عنوان نسخه پایدار انتخاب می‌شود. نام و لینک هر فایل از `assets[].name` و `assets[].browser_download_url` استخراج می‌شود. لینک‌های دانلود فقط از مخزن‌های رسمی `2dust` روی `github.com` پذیرفته می‌شوند. فایل‌ها از سرور شما عبور نمی‌کنند.

> محدودیت: GitHub API برای درخواست‌های بدون احراز هویت محدودیت نرخ دارد. در صورت خطا، سایت لینک مستقیم صفحه رسمی Releases را نشان می‌دهد. دانلود از GitHub ممکن است در برخی شبکه‌ها در دسترس نباشد.

## انتشار در GitHub Pages (بدون کدنویسی)

1. وارد GitHub شوید و یک **New repository** عمومی با نام دلخواه مانند `viperping-download` بسازید.
2. از بخش **Add file → Upload files**، **فایل‌های داخل پوشه پروژه** را در ریشه ریپازیتوری بارگذاری کنید (`index.html`, `style.css`, `app.js`, `favicon.svg`, `.nojekyll`). توجه: فایل مخفی `.nojekyll` ضروری نیست؛ اگر در آپلود پیدا نکردید مشکلی نیست.
3. **Commit changes** را بزنید.
4. از **Settings → Pages → Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
5. Branch را روی `main` و Folder را روی `/ (root)` بگذارید و **Save** را بزنید.
6. سایت پس از انتشار در آدرس `https://USERNAME.github.io/viperping-download/` در دسترس است.

برای تغییر ظاهر، `style.css` و برای تنظیمات رفتار، `app.js` را ویرایش کنید.

## اجرا روی کامپیوتر

در همان پوشه:

```bash
python3 -m http.server 8000
```

بعد `http://localhost:8000` را باز کنید. اطلاعات نسخه‌ها تنها در صورت دسترسی مرورگر به GitHub API بارگذاری می‌شوند.

## اعتبار

برنامه‌ها متعلق به توسعه‌دهنده رسمی `2dust` هستند. این سایت دانلودر مستقل Viper Ping است و ادعای رسمی بودن ندارد.
