# VIPER PING — مرکز دانلود

وب‌سایت ساده دانلود آخرین نسخه رسمی **v2rayNG** و **v2rayN**.

## انتشار در GitHub Pages

1. **تمام فایل‌ها و پوشه‌های داخل ZIP** را در ریشه ریپازیتوری GitHub قرار دهید (نه خود فایل ZIP).
2. در **Settings → Pages**، گزینه **Deploy from a branch** را انتخاب کنید.
3. شاخه **main** و پوشه **/ (root)** را انتخاب و ذخیره کنید.
4. در تب **Actions** منتظر موفقیت انتشار بمانید.

`index.html` باید در ریشه ریپازیتوری باشد. این بسته شامل لوگوی اصلی با پس‌زمینه شفاف، آیکون سایت و هر سه فونت Yekan Bakh است؛ نیازی به آپلود جداگانه فونت نیست.

لینک‌های دانلود به‌صورت خودکار از GitHub Releases پروژه‌های رسمی `2dust/v2rayNG` و `2dust/v2rayN` خوانده می‌شوند. در صورت اختلال یا محدودیت API، لینک صفحه رسمی برنامه نمایش داده می‌شود.
