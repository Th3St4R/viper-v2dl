# مرکز دانلود وایپرپینگ 💚

یه صفحه ساده و خوش‌دست برای دانلود آخرین نسخه‌های **v2rayNG** و **v2rayN**. طراحی این نسخه مخصوص **Viper Ping** و با تم سفید و سبزه.

## لینک‌های وایپرپینگ

- خرید کانفیگ و سرویس: [@viperpingbot](https://t.me/viperpingbot)
- کانال اطلاع‌رسانی: [@viperping](https://t.me/viperping)

## سایت چه کار می‌کنه؟

وقتی کاربر وارد صفحه می‌شه، سایت از بخش Releases گیت‌هاب رسمی توسعه‌دهنده اطلاعات نسخه‌ها رو می‌گیره:

- اندروید (v2rayNG): `https://api.github.com/repos/2dust/v2rayNG/releases?per_page=60`
- ویندوز، لینوکس و مک (v2rayN): `https://api.github.com/repos/2dust/v2rayN/releases?per_page=60`

لینک‌های دانلود مستقیم به فایل‌های رسمی GitHub می‌رن. فایل‌ها روی سرور وایپرپینگ ذخیره یا ویرایش نمی‌شن. سایت بک‌اند یا API Token نمی‌خواد. اگر GitHub API موقتاً در دسترس نباشه، کاربر می‌تونه از لینک صفحه Releases رسمی دانلود کنه.

## چطوری نسخه جدید رو جایگزین سایت قبلی کنم؟

1. فایل ZIP رو Extract کن.
2. وارد ریپازیتوری GitHub خودت شو (مثلاً `Th3St4R/viperping-download`).
3. فایل‌های **داخل پوشه** رو در ریشه ریپازیتوری جایگزین کن: `index.html`، `style.css`، `app.js`، `favicon.svg`، `README.md` و `.nojekyll`.
4. تغییرات رو Commit کن. اگر از وب‌سایت GitHub فایل‌ها رو آپلود می‌کنی، فایل‌های جدید باید جایگزین فایل‌های همنام قبلی بشن، نه اینکه توی پوشه اضافه قرار بگیرن.
5. اگر Pages قبلاً فعال بوده، نیازی به فعال‌سازی مجدد نیست. چند دقیقه بعد صفحه رو با `Ctrl + F5` رفرش کن.

### اگر هنوز GitHub Pages رو فعال نکردی

از داخل **خود ریپازیتوری** به `Settings → Pages` برو، `Deploy from a branch` رو انتخاب کن، Branch رو روی `main` و Folder رو روی `/ (root)` بذار و Save کن.

آدرس سایت با این نام ریپازیتوری:

`https://th3st4r.github.io/viperping-download/`

## اجرای آزمایشی روی کامپیوتر

داخل پوشه فایل‌ها دستور زیر رو اجرا کن:

```bash
python3 -m http.server 8000
```

بعد `http://localhost:8000` رو باز کن. دریافت نسخه‌های واقعی به دسترسی مرورگر به GitHub API نیاز داره.

## نکته

این صفحه متعلق به وایپرپینگه، اما **v2rayNG** و **v2rayN** نرم‌افزارهای مستقلی هستن و توسعه‌دهنده اون‌ها وایپرپینگ نیست.
